Welcome to AutoApplier

AutoApplier turns your master CV into a one-page resume tailored to the job posting you're looking at. It checks the job against your criteria, then asks an LLM to draft a resume using only facts from your CV. It compiles the result to a PDF for you to review.

You stay in control

AutoApplier never submits applications. It reads only the page you're on, when you click. Review every PDF before you send it to an employer.

Get started

  1. Start the backend. From the project folder, run docker run --rm -p 127.0.0.1:2005:2005 --env-file .env autoapplier (see the README for building the image and writing .env).
  2. Connect. In Settings, paste the AUTOAPPLIER_API_KEY from your .env, then click Test connection.
  3. Add your master CV. Paste it or load a .txt / .tex / .md file in Settings. Include everything you might want on a resume.
  4. Set your criteria (title words, locations, minimum pay). Jobs that don't match are skipped without spending an LLM call.
  5. Open a job posting and click the AutoApplier toolbar icon. Check the extracted fields, then click Tailor resume. The PDF downloads to Downloads/AutoApplier/.

Postings on most job boards (Greenhouse, Lever, Indeed, LinkedIn) include structured job data that AutoApplier reads directly. On other pages it makes a best guess you can edit. Selecting the posting text first gives it a cleaner description.
